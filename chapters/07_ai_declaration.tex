\section{AI Usage Declaration}
\label{sec:ai-declaration}

\subsection{Công cụ và phạm vi sử dụng}
Nhóm sử dụng ChatGPT (OpenAI) để đọc đề bài, tổng hợp báo cáo Project 2, mã nguồn và dữ liệu kiểm thử Project 3, đối chiếu số lượng ca và trạng thái chạy, tổ chức nội dung và biên tập sườn báo cáo.

\subsection{Prompt đã cung cấp}
Prompt phân tích yêu cầu Project 3:
\begin{quote}
“Dựa vào nội dung đề bài Project 3, nội dung bài làm Project 2 đã cung cấp, hãy phân tích và tổng hợp các yêu cầu, nhiệm vụ cần thiết để hoàn thành Project 3.”
\end{quote}

\noindent
Prompt tổng hợp bài làm Project 3 của các thành viên:
\begin{quote}
“Các thành viên đã hoàn thành source code và dữ liệu kiểm thử cho Project 3. Kiểm tra toàn bộ source code và dữ liệu kiểm thử, đối chiếu source code với yêu cầu đề bài Project 3 và bài làm Project 2, chỉ ra các điểm mâu thuẫn hoặc cần cải tiến nếu có (không được phép sửa source code).”
\end{quote}

\noindent
Prompt tổng hợp báo cáo mẫu Project 3:
\begin{quote}
"Dựa vào nội dung đề bài Project 3, nội dung bài làm Project 2 đã cung cấp, source code và dữ liệu kiểm thử Project 3, hãy tổng hợp báo cáo mẫu Project 3 theo các mục: phạm vi chức năng và dữ liệu kiểm thử, kết quả và phân tích, nhận xét và giới hạn của AI. Nội dung báo cáo cần có các bảng tổng hợp số lượng ca kiểm thử, kết quả kiểm thử chức năng và phi chức năng, diễn giải kết quả, nhận xét về dữ liệu kiểm thử và giới hạn của AI. Đề xuất các mục cần có thêm (nếu có). Nội dung báo cáo mẫu cần nêu rõ các nội dung nào cần có trong từng mục, các nội dung nào cần đối chiếu kết quả thực tế"
\end{quote}
